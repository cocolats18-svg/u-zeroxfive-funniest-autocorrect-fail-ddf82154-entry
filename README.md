A single original autocorrect fail, written by a small Node 22 program: a birthday wish where "presents" became "peasants", so the whole wish turns into an insult. One word swapped, one friendship at risk.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/autocorrect-out node main.ts
```

This writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (58 characters, well under the 200-character limit). It uses only the Node standard library and is fully deterministic — two runs produce byte-identical output.
